# Configuración del entorno virtual

## 1. Objetivo

Documentar el entorno virtual utilizado para desarrollar el laboratorio SOC.

## 2. Herramienta de virtualización

Se utiliza Oracle VirtualBox para ejecutar Ubuntu en una máquina virtual,
sin modificar directamente el sistema operativo principal del equipo.

## 3. Sistema operativo

- Sistema operativo: Ubuntu 24.04.5 LTS.
- Entorno de ejecución: máquina virtual.
- Hipervisor: Oracle VirtualBox.

## 4. Recursos asignados

- Memoria RAM: aproximadamente 6 GB.
- Procesadores: 4 CPU.
- Almacenamiento: disco virtual de aproximadamente 49 GB.

## 5. Justificación

Ubuntu permite instalar y utilizar herramientas de administración de sistemas,
análisis de registros, redes y ciberseguridad.

VirtualBox proporciona un entorno aislado para realizar prácticas
y experimentos sin afectar directamente al sistema principal.

## 6. Conclusión

Se dispone de un entorno virtual basado en Ubuntu 24.04.5 LTS
para comenzar la implementación y las prácticas del laboratorio SOC.
