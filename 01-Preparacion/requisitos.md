# Requisitos y características del entorno

## 1. Objetivo

Registrar las características del entorno virtual donde se desarrollará el laboratorio SOC.

## 2. Entorno de trabajo

- Sistema operativo: Ubuntu 24.04.5 LTS.
- Plataforma de virtualización: Oracle VirtualBox.
- Memoria RAM: 5,7 GB.
- Procesadores: 4.
- Espacio disponible en disco: 28 GB.

## 3. Observaciones

El entorno cuenta con recursos suficientes para comenzar
las primeras actividades del laboratorio con herramientas
de bajo consumo.

## 4. Conclusión

Se verificaron las características iniciales de la máquina
virtual antes de comenzar la instalación y configuración
de las herramientas del laboratorio SOC.
